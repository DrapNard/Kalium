## Integrated slices and active work

**UI-001 — Protect unsaved documents during New/Open/close.** Implemented in `src/app.rs`; the prompt is modal and Save/Discard/Cancel guard New, Open, and native close. Save cancellation/failure leaves the current project intact. Policy tests and full suite pass; the GUI was not launched, so interaction remains visually unverified.

**S5-001 / S1-001 — Bound image decoding before allocation.** Project PNGs are checked against manifest dimensions and decoder allocation limits before pixels are decoded. Standalone image imports use checked RGBA byte arithmetic and enforce the 512 MiB limit before decode; rejection leaves the document unchanged. Both have regression tests and pass the full suite.

**S1-002 — Headless multi-material artist-core workflow.** A fixture test imports `TwoMaterials.obj`, renders and picks both material slots, checks hit UVs against each set's coverage, paints through those hits, verifies the CPU viewport changes, saves/reopens, and asserts exported per-set pixels. A second app-level flow uses actual down/move/up model-canvas events for a continuous stroke across adjacent Leather triangles, checks Metal remains unchanged, stacks two masked layers, then verifies exact saved/reopened composites and per-set PNG exports. GUI interaction remains visually unverified.

**S2-001 — Analytic CPU picking.** Tests assert perspective-projected pixel-to-UV/material mapping and nearest-surface selection for overlapping triangles. Near-plane clipping is covered by S2-002; degenerate geometry and mirrored-UV tangent behavior are covered by S2-003; transformed/nonuniform-scale picking is covered by S2-004. A glTF fixture verifies baked translation, rotation and nonuniform scale. End-to-end imported picking and seams remain open.

**S2-002 — Near-plane clipping.** The CPU reference rasterizer clips triangles against its camera near plane and fan-triangulates the remaining polygon while interpolating position, normal and UV. Tests compare picked UVs to independent ray/triangle intersections for one and two vertices behind the camera, and confirm fully-behind triangles produce no hits. This does not validate GUI visual behavior.

**S2-003 — Mirrored-UV tangent handedness.** The CPU reference renderer derives tangent-frame orientation from both UV derivatives. A normal-map test confirms a +V sample maps to the same world-space direction for regular and mirrored UVs; a degenerate-triangle test confirms invalid area creates no picking hits.

**S2-004 — Transformed triangle picking.** A translated, rotated and nonuniformly scaled triangle is rasterized and its picked UV is compared against independent world-space ray/triangle barycentrics. This validates the reference renderer's world-space geometry handling; it does not prove transform retention in imported source assets.

**S2-005 / S3-009 — Surface-aware model stroke across a UV seam.** Raster hits retain the source triangle ID and perspective-correct barycentrics. Model strokes crossing triangles with an exactly shared geometric edge paint the corresponding edge points in both UV charts and do not interpolate directly across the atlas gap. Synthetic egui drag coverage confirms both islands change, the gap does not, and one Undo/Redo restores the exact before/after composites. Seam edge matching currently requires exact positions and rejects ambiguous matches. Model pointer jumps now sample at bounded one-logical-pixel intervals, forwarding triangle transitions and the endpoint without adding same-triangle opacity dabs; a three-chart sparse-drag egui test checks each island, the atlas gap and single Undo/Redo. Imported mesh seam acceptance and desktop/tablet pointer behavior remain open.

**S1-003 — Bounded assembled mesh import and validation.** OBJ/glTF assembly checks aggregate vertex/index bounds before appending. Shared `Mesh::validate` also enforces the 1,050,000-vertex limit, including project deserialization and recovery replay paths that bypass the import assembler. OBJ/MTL source bytes, glTF document/GLB files, and aggregate external/data buffers are capped at 128 MiB; external references must remain under the asset directory; and unused glTF images are not decoded. glTF hierarchy depth is capped at 256, material slots are capped at 256 before material-name allocation, accessor counts are checked, and malformed primitive indices are rejected before offsetting. Regression tests cover size limits, exact/over material caps, image handling, and path escapes. Decoder amplification, malformed-input fuzzing and peak-memory profiling remain open.

**S1-005 — OBJ/MTL expansion preflight.** A bounded first pass rejects oversized OBJ source attributes, repeated `f`/`l` corner/index expansion, object/group/material boundaries and lines before invoking `tobj`; referenced MTL files are preflighted for source/line size, material-slot count, and unknown parameter count/key/value bounds before material parsing. Import-level repeated-index face and line fixtures confirm rejection before geometry assembly. The existing parser remains responsible for syntax and index validity; malformed-input fuzzing and parser-level memory profiling remain open.

**S1-011 — Bounded glTF scene assembly.** glTF import rejects more than 256 materials before allocating owned display names, and limits traversal of the selected scene graph to 100,000 node visits to bound repeated child-reference amplification. Tests preserve exact-cap unnamed material order, reject 257 materials, accept the helper visit boundary, and reject an imported scene that repeats a child beyond the total visit cap. Malformed-input fuzzing and peak-memory profiling remain open.

**S5-004 — Separate validated recovery checkpoint API.** `project::save_checkpoint` writes a caller-selected checkpoint archive using the same validation and checkpoint-local transactional `.tmp` replacement as a normal save; `load_checkpoint` uses the bounded project loader. The global checkpoint has no source-project identity or timestamp, and recovery has no additional confirmation for a clean open document. This is a manual checkpoint workflow, not timed autosave/background saving.
