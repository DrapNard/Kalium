## Integrated slices and active work

**UI-001 — Protect unsaved documents during New/Open/close.** Implemented in `src/app.rs`; the prompt is modal and Save/Discard/Cancel guard New, Open, and native close. Save cancellation/failure leaves the current project intact. Policy tests and full suite pass; the GUI was not launched, so interaction remains visually unverified.

**S5-001 / S1-001 — Bound image decoding before allocation.** Project PNGs are checked against manifest dimensions and decoder allocation limits before pixels are decoded. Standalone image imports use checked RGBA byte arithmetic and enforce the 512 MiB limit before decode; rejection leaves the document unchanged. Both have regression tests and pass the full suite.

**S1-002 — Headless multi-material artist-core workflow.** A fixture test imports `TwoMaterials.obj`, renders and picks both material slots, checks hit UVs against each set's coverage, paints through those hits, verifies the CPU viewport changes, saves/reopens, and asserts exported per-set pixels. GUI interaction remains visually unverified.

**S2-001 — Analytic CPU picking.** Tests assert perspective-projected pixel-to-UV/material mapping and nearest-surface selection for overlapping triangles. Near-plane clipping is covered by S2-002; degenerate geometry and mirrored-UV tangent behavior are covered by S2-003; transformed/nonuniform-scale picking is covered by S2-004. A glTF fixture verifies baked translation, rotation and nonuniform scale. End-to-end imported picking and seams remain open.

**S2-002 — Near-plane clipping.** The CPU reference rasterizer clips triangles against its camera near plane and fan-triangulates the remaining polygon while interpolating position, normal and UV. Tests compare picked UVs to independent ray/triangle intersections for one and two vertices behind the camera, and confirm fully-behind triangles produce no hits. This does not validate GUI visual behavior.

**S2-003 — Mirrored-UV tangent handedness.** The CPU reference renderer derives tangent-frame orientation from both UV derivatives. A normal-map test confirms a +V sample maps to the same world-space direction for regular and mirrored UVs; a degenerate-triangle test confirms invalid area creates no picking hits.

**S2-004 — Transformed triangle picking.** A translated, rotated and nonuniformly scaled triangle is rasterized and its picked UV is compared against independent world-space ray/triangle barycentrics. This validates the reference renderer's world-space geometry handling; it does not prove transform retention in imported source assets.

**S1-003 — Bounded assembled mesh import.** OBJ/glTF assembly checks aggregate vertex/index bounds before appending. OBJ/MTL source bytes, glTF document/GLB files, and aggregate external/data buffers are capped at 128 MiB; external references must remain under the asset directory; and unused glTF images are not decoded. glTF hierarchy depth is capped at 256, accessor counts are checked, and malformed primitive indices are rejected before offsetting. Regression tests cover size limits, image handling, and path escapes. Decoder amplification and malicious-file fuzz coverage remain open.

**S3-001 — Stroke segmentation regression tests.** A long UV jump is verified to apply one destination dab (and one mirrored dab) while leaving its source untouched; a connected segment still interpolates through interior texels. No behavior change was required by this test slice.

**S5-002 — Validated temp-project recovery.** `project::load_with_recovery` prefers a fully valid primary file and only falls back to a fully validated sibling `.tmp`. It never promotes or overwrites the primary. The UI marks recovered content unsaved and detaches its Save path so it must be preserved through Save As. Tests cover primary precedence, missing/corrupt temp, and injected replace failure; autosave and power-loss durability are not implemented.

**S5-003 — Preserve forward-compatible project metadata.** Unknown JSON fields survive load/save at project, texture-set, layer, mesh and vertex levels while known fields retain typed validation and unexpected ZIP payload entries remain errors. Invalid layer/set metadata is checked before image payload decoding. Regression tests cover metadata round trips and preflight ordering. Removed-layer undo accounting includes retained extension data under the 96 MiB history cap.

**S5-004 — Separate validated recovery checkpoint API.** `project::save_checkpoint` writes a caller-selected checkpoint archive using the same validation and checkpoint-local transactional `.tmp` replacement as a normal save; `load_checkpoint` uses the bounded project loader. File → Save recovery checkpoint and Recover global checkpoint use one per-user `recovery-v1.kalium` archive across projects, and recovered content requires Save As. Saving is rejected when the checkpoint is also the open primary project. A regression test round-trips multi-layer/multi-set pixels, masks, material bindings and unknown metadata while asserting the separate primary archive remains byte-identical. The global checkpoint has no source-project identity or timestamp, and recovery has no additional confirmation for a clean open document. This is a manual checkpoint workflow, not timed autosave/background saving.

**S6-001 — UV-aware export padding.** Per-set exports can copy the nearest same-set UV-covered texel into a configurable 0–256 texel gutter. The squared Euclidean distance transform is deterministic, uses a single `u32` map plus O(size) scratch, and chooses the lower linear source index on ties. Radius zero follows the legacy path byte-for-byte. Export options are exposed in the GUI; Blender smoke covers default zero-padding output only.

**S4-002 — Channel-aware compositing.** Base Color RGB blends are evaluated in linear light and encoded to sRGB at composite output. Normal layers decode to unit vectors, interpolate orientations using effective source alpha × layer opacity × mask, and normalize; RGB blend modes are not applied to Normal. Numeric regression tests cover half-opacity red/blue and non-flat normal interpolation. Scalar channels continue to blend their normalized byte data directly.

**S4-003 — Emissive color compositing.** Emissive layer RGB uses the same linear-light Normal/Multiply/Add blend math as Base Color, with source alpha × layer opacity × mask as the interpolation weight and sRGB bytes at composite output. Numeric tests cover masked quarter-weight red and half-alpha Add blending.

**UI-002 — Bounded undo for layer commands and properties.** History now records add, duplicate, remove, reorder and layer property edits alongside sparse pixel deltas. Removed layers move into history and restore their mask, channels and properties; add/duplicate redo uses a recipe to avoid retaining a second pixel payload. Property edits coalesce by layer ID. A removed layer above the 96 MiB history limit is rejected before mutation. Mixed stroke→remove→undo, duplicate/reorder/property replay, exact deletion limit, and oldest-entry count/byte-budget eviction tests pass. Interactive GUI use remains visually unverified.

**S3-002 — Linear-light Base Color brush blending.** Base Color paint stamps decode source and destination sRGB RGB, perform straight-alpha source-over in linear light, and encode the stored result. Numeric tests cover half-opacity red over blue, painting over transparency and zero-opacity identity. Other channels retain their prior brush blend rules.

**S3-003 — Linear-light Emissive brush blending.** Emissive stamps use the same straight-alpha linear-light source-over as Base Color. Tests cover half-opacity red over blue and painting over a transparent pixel. Other channels retain their existing stamp rules.

**S3-004 — Vector-aware Normal brush stamps.** Normal stamps decode signed vectors, source-over using stroke coverage and alpha, normalize, then encode back; erasing changes coverage while retaining direction. Numeric tests cover half-opacity tilt, repeated-stamp unit length, transparent destination coverage, and eraser behavior.

**S4-004 — Detail Normal layer composition.** The Layers blend selector includes Detail Normal. It weights the top tangent-space detail vector against neutral using pixel alpha × layer opacity × mask, then applies reoriented normal mapping to the accumulated normal. Tests cover the analytic RNM result, normalization, partial opacity/mask and zero-weight identity. Other channels treat this mode as Normal blending.

**S4-005 — Undoable imported texture layers.** Image import records its full layer payload in bounded history, so undo removes the import and redo restores its exact pixels and name. Existing prior history remains available; import rejects before leaving an unrecorded layer if its payload exceeds the history limit.

**S1-004 — Transformed glTF artist-core workflow.** A generated embedded triangle fixture with translation, rotation and nonuniform scale is imported, checked against expected baked positions, rendered and picked by material slot, clipped to its UV coverage, painted at the picked UV, saved/reopened, and exported with pixel assertions. This headless workflow does not verify the GUI.

**S1-005 — Nonuniform-scale normal transform.** A glTF fixture with a known normal and tangent under nonuniform node scale verifies inverse-transpose normal transformation, unit length, finiteness, and perpendicularity to the transformed tangent. The existing importer implementation passed without modification.

**S6-002 — Packed export channel oracle.** Exact pixel tests verify AO/R/Metal packing, Unity metallic/smoothness packing, and a separate Base Color alpha map whose RGB comes from Base Color and alpha byte comes from the Opacity channel's red value. Blender's smoke separately loads the packed ORM image and verifies Roughness/Metallic node links; AO renderer behavior and rendered appearance remain open.

**S6-003 — Normal map Y convention.** Active-set and all-set export APIs support OpenGL (+Y) and DirectX (−Y) output. DirectX export inverts only the Normal PNG's green byte after compositing/padding; OpenGL remains the default and preserves legacy output. Exact pixel tests cover active/all-set paths; downstream engine imports remain unverified.

**S6-004 — Blender export import smoke.** Exported the demo project's 11 maps, imported `TwoMaterials.obj` into Blender 5.2.2, loaded Base Color (sRGB), packed ORM (Non-Color, G→roughness/B→metallic, R retained as AO source), Normal (Non-Color) and Emissive (sRGB), connected the applicable Principled shader inputs, and checked those image nodes and links after saving/reopening a `.blend`. This validates file loading and node graph construction, not rendered visual fidelity. The same exported set was assigned to every OBJ material slot.

**S7-001 — Deterministic CPU GGX reference shader.** The software viewport now decodes Base Color and Emissive from sRGB, evaluates a Cook–Torrance GGX direct light with Smith masking and Schlick Fresnel plus a constant Lambertian ambient fill, then encodes display RGB. AO affects the ambient fill only; solo-channel previews remain raw map bytes. Numeric BRDF and transfer-function oracles, safe nonfinite handling, repeated-frame equality and a fixed 200×200 cube center-pixel tolerance pass. IBL, UI lighting controls, broader image baselines and GPU shading are not implemented.

**S7-002 — Edited-map frame refresh regression.** A deterministic viewport test renders the default material, edits every Base Color texel, rebuilds the composited `Material` snapshot, and confirms the next rendered frame differs. This verifies the renderer data-refresh contract in isolation; it does not exercise app invalidation or GUI frame scheduling.

**S8-001 — CPU mesh-map bake primitives.** A bounded CPU UV raster pass interpolates imported mesh positions and normalized world normals, filters triangles by material-to-TextureSet binding, and gives overlapping UVs to the first covering triangle in mesh index order. It checks an atomic cancellation flag at triangle and row boundaries and returns no partial result on cancellation. CLI `bake-mesh-maps` writes world-normal, normalized-position and coverage PNGs plus encoding/bounds metadata. Analytic position/normal, binding, overlap, cancellation, size and binding-count tests pass, including extreme finite UV regression coverage. A separate high-to-low world-normal projection primitive has nearest-hit ray tests and a cage-distance test; the API requires already aligned low/high meshes, so the CLI does not expose it yet. Outputs are standalone; extra bake channels, persistence and generator use remain unimplemented.

**S3-005 — Stroke-local tiled undo capture.** Interactive stamps request their inclusive UV bounds before mutation. History snapshots each intersected 64×64 tile once, stores changed rows only, and preserves whether a channel was absent before the stroke. A 4096² test exercises the real brush path and verifies a one-tile capture stays below 40 KiB; mask, undo/redo, repeated capture and over-budget rollback are also covered. Strokes whose undo capture exceeds the 96 MiB cap are rolled back before completion, preserving previous undo and redo entries. Fill/clear operations retain their full-image snapshot path, and GUI runtime/performance measurements remain outstanding.

**UI-003 / S4-006 — Drag-and-drop layer reorder.** Each layer row is an egui drag source and drop target. Dropping moves the dragged layer to the target's stack index, retains selection by stable layer ID, marks the project dirty and records one undoable move. Headless egui pointer-event coverage performs an actual row drag, then verifies stack order, undo and redo. Self-drop and invalid boundary indices are no-ops. Desktop visual interaction remains unverified.

**S13-006 — Incremental paint-region compositing.** A paint operation collects unique 64×64 tiles touched by its stamps, composites those regions for the edited Texture Set and channel, patches the cached material image, and uploads the changed region to the active egui UV texture. Two document tests compare cropped output with full composites across channels, blend modes, masks, visibility and channel enablement; an app cache test compares the patched map byte-for-byte with a full rebuild. Cache misses and other edits retain the full invalidation path. This reduces composition and UV texture upload work for active painting; it does not benchmark end-to-end stroke latency or change the full-frame CPU viewport renderer.
